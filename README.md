An AI-assisted analytics platform that turns uploaded business datasets into decision-ready insights. Its workflows include KPI analysis, anomaly detection, forecasting, risk assessment, root-cause analysis, scenario simulation, and recommendations.

### PahchanAI — Face Recognition & Identity Matching

A computer-vision project that combines face detection, facial embeddings, and vector similarity search to surface potential identity matches for human review.

- **Stack:** React, Node.js, Express, MongoDB, Python, OpenCV, FaceNet, FAISS
- **Highlights:** Face preprocessing, embedding generation, similarity search, and match review
- **Repository:** [harshvardhan-it/PahchanAI](https://github.com/harshvardhan-it/PahchanAI)
- **Live application:** [pahchan-ai.vercel.app](https://pahchan-ai.vercel.app)

### SSSMP Portal — Bilingual Membership Platform

A Hindi-English membership portal for a teachers’ organization in Madhya Pradesh, with public information, guided member registration, printable digital membership cards, and State → District → Block administrative views.

- **Stack:** React, TypeScript, Vite, Tailwind CSS
- **Highlights:** Hindi-first interface, language toggle, multi-step registration, member cards, and hierarchical administration
- **Repository:** [harshvardhan-it/sssmp-portal](https://github.com/harshvardhan-it/sssmp-portal)

## Run Locally

### Prerequisites

- Node.js (a current version compatible with the installed Vite release)
- npm

### Setup

```bash
git clone https://github.com/harshvardhan-it/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Vite will print the local development URL in the terminal.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the local development server |
| `npm run build` | Run TypeScript project checks and create a production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run Oxlint |
